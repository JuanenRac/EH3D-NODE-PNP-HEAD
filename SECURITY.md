# Security policy

EH3D-NODE-PNP-HEAD is at its first steps. If you find a vulnerability, or an instruction that could make somebody run something on a machine without its limits, please report it.

## Reporting a problem

Please report it privately to **electrohobby3d@gmail.com**, with what you found and where. Do not open a public issue for it. You will get an answer as soon as possible; this is a one-person project.

Only the latest version is supported.

This node moves hardware: a report about a way to make it move without the token, to keep it moving when the server is lost, or to loosen an interlock or a limit is a vulnerability, and is read first.
